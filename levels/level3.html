📚 الدرس: الشروط في Python

الشروط هي قرارات يتخذها البرنامج. مثل: "إذا كان الباب مفتوحاً، ادخل!"

if
password == "secret"
:
print("Access Granted!")
else
:
print("Access Denied!")

🔍 عوامل المقارنة:

  • == يساوي
  • != لا يساوي
  • > أكبر من
  • < أصغر من
  • >= أكبر أو يساوي
  • and و
  • or أو
