📚 الدرس: أوامر Linux الأساسية

في عالم الاختراق، Terminal هو سيفك! هذه الأوامر الخمسة هي حجر الأساس:

pwd

📍 Print Working Directory - يظهر لك المجلد الحالي الذي تعمل فيه

ls

📂 List - يعرض جميع الملفات والمجلدات في المكان الحالي

cd [folder]

🚪 Change Directory - ينقلك إلى مجلد آخر (مثل فتح باب!)

cat [file]

📖 Concatenate - يعرض محتوى الملف (مثل قراءة رسالة سرية!)

clear

🧹 ينظف الشاشة ليبدأ من جديد

💻 محاكي التيرمنال التفاعلي

جرب الأوامر بنفسك! اكتب help لرؤية جميع الأوامر المتاحة.

🎯 المهمة: اخترق الباب الإلكتروني

هناك ملف سري يحتوي على كلمة المرور. استخدم الأوامر لتجد الملف وقراءته!

📌 خطوات المهمة:

  1. استخدم ls لمعرفة ما يوجد في المجلد
  2. استخدم cd secret_room للدخول للغرفة السرية
  3. استخدم ls مرة أخرى
  4. استخدم cat password.txt لقراءة كلمة المرور
🎉

أحسنت! لقد وجدت كلمة المرور!
