📚 الدرس: Web Scraping (استخراج بيانات المواقع)

Web Scraping هو فن استخراج البيانات من صفحات الويب! نستخدم Python لـ "قراءة" HTML واستخراج ما نريد.

🌐 جلب الصفحة

import requests
from bs4 import BeautifulSoup

url = "https://omega.com"
response = requests.get(url)
soup = BeautifulSoup(
    response.text,
    'html.parser'
)

🔍 البحث في HTML

# البحث باسم الوسم
titles = soup.find_all('h1')

# البحث بـ class
secrets = soup.find_all(
    'div',
    class_='secret'
)

# استخراج النص
for item in secrets:
    print(item.text)
